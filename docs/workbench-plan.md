# 学习工作台设计草案

状态：规划。下列功能尚未实现，不能当作当前脚本能力。

## 用户问题

阅读资料时遇到概念，提问后答案留在聊天中，原始出处、当时的疑问和后续理解难以一起找回。

## 拟验证的最小流程

选区 → 附加疑问与出处 → 交给已选择的 AI → 人工确认回答 → 形成可编辑知识卡片。

卡片拟包含：原文、来源、我的问题、AI 解释、我的理解、待核实内容、关联概念和学习状态。AI 生成的解释与本人理解分别显示。

阅读现场只收集必要内容；工作台负责后续整理。先验证选区到目标对话的实际接收，再决定采用人工回收答案或直接接入 API，避免假设外部客户端会自动把回答传回。

## 验收方向

确认原文与目标对话一致；空选区不发送；失败可见；来源可回查；重复概念可合并；缺乏证据的解释标记待核实。当前仓库没有实施或通过这些完整流程的验收。
