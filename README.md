# 划词提问与学习工作台原型

面向阅读简历、技术资料时反复切换窗口提问的问题，先用一个 Windows 快捷键脚本缩短“选中文字 → 交给 AI”的路径，再探索来源、问题与学习笔记的整理方式。

**当前可运行部分是豆包工作客户端的选区发送脚本。学习卡片、来源自动保存、回答回收与知识库同步属于后续方案，尚未实现。** 本项目不内置模型，也不是独立 Agent Harness。

## 已有功能

- 选中文字后按 `Ctrl+Q`，复制选区，加上 `【简历学习】` 前缀。
- 查找已打开的豆包工作窗口，优先尝试 UI Automation 定位输入区，失败时尝试按窗口位置点击。
- 粘贴并按回车，再尝试返回原窗口；`Ctrl+Shift+Q` 退出。

## 安装与运行

Windows、Python 3.12，以及已打开的豆包工作桌面客户端。先进入希望接收消息的对话。

```powershell
python -m pip install -r requirements.txt
python selection_to_ai.py
```

也可双击 `start.bat`。启动脚本使用项目相对路径，不依赖作者电脑的用户名或 Python 安装目录。

顶部 `HOTKEY`、`WINDOW_KEYWORD` 可调整；消息前缀在 `on_hotkey()` 中修改。修改窗口关键词并不代表已适配其他客户端，Codex 等目标未在本仓库验证。

## 实际边界

触发快捷键会操作剪贴板、鼠标与键盘，并自动按回车。请先用无敏感测试短句验证目标对话。客户端界面变化、权限、窗口状态或输入框识别失败，都可能导致未发送或发送位置不符；控制台完成提示只表示操作序列执行，不能代替目标对话的接收回执。

原脚本关闭了 PyAutoGUI 角落急停，请用退出热键或关闭控制台停止。剪贴板不会恢复；新选区与原剪贴板相同时可能被误判为空。公开版仅记录选区长度，不输出所选正文；运行日志和真实简历不入库。

## 项目过程与后续设计

这一原型来自招聘工作中的实际查词需求：把公司、岗位或技术概念带入 AI 对话，减少手动复制与切换。脚本通过 AI 辅助开发；公开整理时移除了本机绝对路径和选区正文日志。

下一步设计见 [学习工作台方案](docs/workbench-plan.md)。重点是保留“为什么问、来自哪里、后来理解了什么”，先验证真实需求和接收通道，再扩展工作台。
