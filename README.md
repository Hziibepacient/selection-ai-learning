# 划词直达豆包工作工具（v4）

A Windows global-hotkey bridge that sends your text selection to the Doubao Work desktop client.

划选文字，按 `Ctrl+Q`，自动将选区加上 `【简历学习】` 前缀，粘贴到已打开的「豆包工作」对话并按回车发送，随后尝试切回原窗口。适合阅读简历或技术资料时，把公司名、技术名词交给豆包讲解。

本仓库现以这份实际使用的豆包工具为准，已移除旧的学习工作台设计。仓库地址沿用 `selection-ai-learning`。

## 功能

- `Ctrl+Q`：复制选区 → 查找豆包工作窗口 → 定位输入框 → 粘贴并回车 → 尝试返回原窗口。
- 优先通过 UI Automation 定位输入框，失败时尝试物理点击窗口下方输入区。
- 控制台即时输出运行日志；`Ctrl+Shift+Q` 退出。

## 安装与运行

需要 Windows、Python 3.12+ 和「豆包工作」桌面客户端。提供的原版工作包记录了 Python 3.12.4 的使用环境；本次仓库更新未重新实测桌面发送。

在项目目录打开终端，使用同一 Python 解释器安装依赖并运行：

```powershell
py -3.12 -m pip install -r requirements.txt
py -3.12 划词直达豆包.py
```

也可在安装依赖后双击 `启动划词直达.bat`。启动器优先使用 `py -3.12`，找不到 `py` 时使用 PATH 中的 `python`，脚本路径自动取启动器所在目录。使用其他 Python 版本时，可相应修改启动器的版本参数。

PATH 中的 `python` 可能指向另一套未安装依赖的环境。若未安装 Python Launcher，可用自己的解释器完整路径分别执行 `-m pip install -r requirements.txt` 和主脚本。

先打开豆包工作并进入希望接收消息的对话，再启动脚本、划选文字并按热键。程序会自动发送，请先用无敏感内容的短句确认实际落点。

## 配置

在 `划词直达豆包.py` 顶部修改：

```python
HOTKEY = 'ctrl+q'
WINDOW_KEYWORD = '豆包工作'
```

消息前缀在 `on_hotkey()` 中：

```python
message = f'【简历学习】{selected_text}'
```

本工具仅负责把选区送入对话，讲解方式取决于豆包侧的对话设置。修改窗口标题关键词不代表已完成其他客户端的适配。

## 排障

- **启动失败或缺少模块**：查看控制台错误，用启动脚本实际选择的解释器重新执行 `-m pip install -r requirements.txt`。
- **按热键没反应**：确认控制台仍在运行，先划选文字，查看是否出现 `[触发]` 日志。新选区与原剪贴板相同时会被跳过；可先复制不同内容再试。
- **找不到窗口**：确认客户端已打开，调整 `WINDOW_KEYWORD` 以匹配实际窗口标题。
- **能激活但没发送或落点不对**：客户端改版可能影响 UIA 关键词匹配或输入区位置。检查 `activate_and_click_input()` 中的关键词及 `_fallback_click_input_area()` 中的 `0.88` 高度比例，调整后以测试短句核对。

## 使用边界与日志

主程序保留工作包原始版本，操作剪贴板、鼠标与键盘，并自动按回车。剪贴板不会恢复；窗口置前、输入框定位和返回原窗口可能失败。控制台的 `[完成]` 表示发送操作序列已执行，仍需到目标对话确认接收。

脚本关闭了 PyAutoGUI 的鼠标角落急停，可使用退出热键或关闭控制台停止。客户端窗口布局、权限或多屏位置变化可能影响点击落点。

日志默认输出到控制台，**包含选区长度及前 50 字正文**。主程序不自行保存日志文件；如自行重定向输出，请妥善保管。运行日志、真实简历、交接材料和打包中间产物不纳入仓库。文字会通过客户端发送给豆包，请按实际资料的使用权限操作。
